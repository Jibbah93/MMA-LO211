# MMA-LO211 — Materials Management & Forecasting

Course materials for the materials management forecasting sequence:
demand analysis, forecasting, and order-quantity decisions built on the
SAP Global Bike (GBI) case study, implemented first in Excel and then
in Python.

## How to use these notebooks (students)

1. Click an **Open in Colab** badge below.
2. In Colab, choose **File → Save a copy in Drive** — work only in your copy.
3. When finished: **File → Download → Download .ipynb**, then submit
   that file in Canvas.

Do not request edit access to these files; your own Drive copy is
where all work happens.
